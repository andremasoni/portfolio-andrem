Order Management API

Concluído

API REST de pedidos: produtos, clientes, pedido com múltiplos itens e cálculo de totais.

Decisão técnica

JWT com refresh token, para o access token expirar rápido sem forçar login a cada expiração.

  • Java 21
  • Spring Boot 3
  • JPA / Hibernate
  • MySQL
  • JWT
https://github.com/andremasoni/order-management-api

Spring Auth API

Concluído

Serviço de autenticação isolado, feito para aprofundar Spring Security em vez de copiar configuração pronta.

Decisão técnica

Cadeia de filtros própria, proteção de endpoints por papel e resposta padronizada quando a autenticação falha.

  • Java
  • Spring Boot
  • Spring Security
  • JWT
https://github.com/andremasoni/spring-auth-api
