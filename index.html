Eu construo o que resolve o problema que eu mesmo enfrento.

Trabalho com a rotina fiscal e administrativa de TI na Clariens: lançamento e conferência de notas, contratos, orçamento. Toda vez que uma dessas tarefas se repetia, eu parava e transformava ela em um fluxo automatizado.

Foi assim que cheguei em backend. Hoje construo APIs REST em Java 21 e Spring Boot 3 pelo mesmo motivo: são sistemas que executam uma regra melhor do que uma pessoa executaria na mão, toda vez, sem cansar.

Order Management API

Concluído

API REST de gestão de pedidos: cadastro de produtos e clientes, criação de pedido com múltiplos itens e cálculo de totais.

Decisão técnica

Autenticação stateless com JWT e refresh token, para o access token expirar rápido sem obrigar o usuário a fazer login de novo a cada expiração.

  • Java 21
  • Spring Boot 3
  • JPA / Hibernate
  • MySQL
  • JWT
github.com/sqlandr3/order-management-api

Spring Auth API

Concluído

Serviço de autenticação e autorização isolado, construído para aprofundar Spring Security em vez de copiar a configuração pronta de outro projeto.

Decisão técnica

Cadeia de filtros própria para emissão e validação de token, com proteção de endpoints por papel e resposta padronizada quando a autenticação falha.

  • Java
  • Spring Boot
  • Spring Security
  • JWT
github.com/sqlandr3/spring-auth-api

Warehouse Management System

Em desenvolvimento

Gestão de estoque e pedidos. É onde estou tratando o que os projetos anteriores não cobriam: separação de camadas, versionamento de banco, testes de integração e observabilidade.

Decisão técnica

Migrations versionadas com Flyway e testes de integração em container com Testcontainers, para o teste rodar contra o mesmo banco da aplicação em vez de um banco em memória que se comporta diferente.

  • Java 21
  • Spring Boot 3
  • PostgreSQL
  • Flyway
  • Docker
  • Testcontainers
  • OpenAPI
  • GitHub Actions
